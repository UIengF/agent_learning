---
name: test-debugging
description: Diagnose failing tests or checks using command output, targeted reads, and small fixes.
---

Use this skill when the task mentions failing tests, CI, pyright, ruff, or runtime errors.

Workflow:

1. Capture the exact failing command output.
2. Locate the failing symbol, file, or assertion.
3. Read the minimum relevant code and tests.
4. Patch the root cause rather than weakening tests.
5. Re-run the focused failing command when allowed.
