---
name: repo-understanding
description: Inspect repository structure, identify relevant files, and summarize code context before edits.
---

Use this skill when the task requires understanding an unfamiliar repository.

Workflow:

1. Inspect git status and file layout.
2. Search for user-mentioned symbols, files, and error messages.
3. Read only the smallest relevant file sections.
4. Summarize the likely ownership boundary before proposing edits.
